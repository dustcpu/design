# 逐梦前行，心绘中大 · 中山大学招生概念站

> 2026 年中山大学招生设计大赛 · 网页类参赛作品

一个单页招宣互动概念站，围绕"三校区五校园"与中大校训展开，用滚动驱动的书法书写动画作为核心视觉记忆点。

## 本地预览

直接双击 `index.html` 即可在浏览器中打开（推荐 Chrome / Edge）。

如需本地服务器预览（可选）：

```bash
# Python
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 页面结构

| 区块 | 内容 |
| --- | --- |
| 导航 | 锚点跳转至各板块 |
| Hero | 大标题 + 校徽 |
| 五校园长廊 | 南校园怀士堂 / 北校园中山医红楼 / 东校园图书馆 / 深圳校区图书馆 / 珠海校区天琴中心 |
| 校训书写 | 滚动驱动，一笔一划写出"博学审问慎思明辨笃行"，写完淡化成背景 |
| 数字里的中大 | 五项办学数据 |
| 招生服务入口 | 学校概况 / 院系专业 / 招生章程 / 招生计划 / 历年分数 / 联系院系 |
| 结尾 | 公众号与小程序二维码 |
| Footer | 招生办联系方式 |

## 技术说明

- 纯静态单页，原生 HTML / CSS / JavaScript，无构建工具、无框架依赖
- 校训书写：基于书法楷体笔画轮廓数据，沿运笔中线逐笔揭示，滚动进度直接映射书写行程，支持正向书写与回滚擦除
- 配色：米白纸 `#F5F1E8`、墨绿 `#1F4D38`、砖红 `#8B3A2E`、金 `#C9A24B`
- 响应式适配桌面与移动端
